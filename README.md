# ML Maze

ML Maze is a reinforcement learning agent that learns to navigate a maze. The goal is to develop a Deep Q-Network (DQN) from scratch and visualize its learning progress.

## Current Status

- 5×5 maze with a start, a goal, and obstacles
- Agent movement with four actions and collision detection
- Gymnasium environment with `reset()` and `step()`
- PyTorch Q-network, epsilon-greedy action selection, and replay buffer
- Tests for core components

## Planned

- Train the agent with DQN
- Add a Pygame visualization
- Support user-defined obstacles
